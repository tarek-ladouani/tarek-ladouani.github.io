📝 Gästebuch – Case Study

01 — Overview

Ich habe eine dynamische Webanwendung entwickelt – ein Gästebuch, in dem Besucher Name und Nachricht hinterlassen können. Die Einträge werden in einer MariaDB-Datenbank gespeichert und live angezeigt.

02 — Technologies

  • PHP 8.2 (Backend)
  • MariaDB (Datenbank)
  • MySQLi (Datenbankzugriff)
  • HTML/CSS (Frontend)
  • Docker (Containerisierung)

03 — Features

  • Formular für Name + Nachricht
  • Speicherung in der Datenbank mit INSERT
  • Anzeige aller Einträge mit SELECT
  • Zeitstempel mit deutscher Zeitzone
  • Läuft in einem Docker-Container

04 — Database Schema

CREATE TABLE gästebuch (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    nachricht TEXT NOT NULL,
    erstellt DATETIME DEFAULT CURRENT_TIMESTAMP
);

05 — Problems

Problem #1: PHP konnte keine Verbindung zur Datenbank herstellen.

Der PHP-Container konnte die MariaDB nicht erreichen. Fehlermeldung: SQLSTATE[HY000] [2002] Connection refused

Problem #2: Uhrzeit der Einträge war falsch.

Die Einträge wurden mit UTC-Zeit gespeichert, nicht mit deutscher Zeit.

06 — Solution

Lösung #1: Docker-Netzwerk konfigurieren.

Mit docker logs die Fehlerlogs geprüft. Die Container wurden im selben Netzwerk verbunden und die Umgebungsvariablen für die Datenbankverbindung korrigiert. PHP-Erweiterung php-mysql nachinstalliert.

Lösung #2: Zeitzone in PHP setzen.

In der PHP-Konfiguration wurde date.timezone = Europe/Berlin gesetzt.

07 — What I Learned

  • PHP + MySQLi für Datenbankzugriff
  • SQL-Befehle (CREATE, INSERT, SELECT)
  • Container-übergreifende Kommunikation
  • Troubleshooting mit Logs
  • Konfiguration von PHP (Zeitzone, Erweiterungen)
