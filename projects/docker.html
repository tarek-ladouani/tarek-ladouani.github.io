🐳 Docker Homelab – Case Study

01 — Overview

Ich habe einen alten Dell-Laptop als Linux-Server eingerichtet, um Containerisierung mit Docker zu lernen. Ziel war es, eine Multi-Container-Umgebung mit Webserver, PHP und Datenbank aufzusetzen.

02 — Hardware

  • Dell-Laptop
  • BIOS-Version: 1.8.0
  • RAM: 4GB → 8GB (Upgrade)
  • Festplatte: 256GB SSD

03 — Software

  • Windows 11 mit WSL2
  • Ubuntu 24.04 (WSL2)
  • Docker & Docker Compose
  • Nginx (Webserver)
  • PHP 8.2
  • MariaDB (Datenbank)

04 — Architecture

05 — Problems

Problem #1: PHP konnte keine Verbindung zur Datenbank herstellen.

Der PHP-Container konnte die MariaDB nicht erreichen. Die Fehlermeldung war: SQLSTATE[HY000] [2002] Connection refused

Problem #2: Uhrzeit der Einträge war falsch.

Die Gästebuch-Einträge wurden mit UTC-Zeit gespeichert, nicht mit deutscher Zeit.

06 — Solution

Lösung #1: Docker-Netzwerk konfigurieren.

Mit docker logs die Fehlerlogs geprüft. Dann die docker-compose.yml angepasst: Die Container wurden im selben Netzwerk verbunden und die Umgebungsvariablen für die Datenbankverbindung korrigiert. Außerdem wurde die PHP-Erweiterung php-mysql nachinstalliert.

Lösung #2: Zeitzone in PHP setzen.

In der PHP-Konfiguration wurde date.timezone = Europe/Berlin gesetzt.

07 — What I Learned

  • Containerisierung mit Docker und Docker Compose
  • Netzwerkkommunikation zwischen Containern
  • Troubleshooting mit docker logs
  • PHP + MySQLi für Datenbankzugriff
  • SQL-Befehle (CREATE, INSERT, SELECT)
  • Konfiguration von PHP (Zeitzone, Erweiterungen)
