Homelab – Vom Büro-PC zum Server

Hardware BIOS Optimierung

🎯 Ziel: Einen alten Dell-Laptop als Server nutzbar machen.

🛠️ Hardware: Dell-Laptop, BIOS 1.8.0, RAM 4GB → 8GB.

⚠️ Problem: Bloatware und unnötige Dienste verbrauchten Ressourcen.

🔍 Analyse: Task-Manager und Autostart überprüft.

✅ Lösung: SupportAssist, Dell Update und Co. deinstalliert, visuelle Effekte deaktiviert.

📈 Ergebnis: System läuft stabil und hat genug RAM für Virtualisierung.

💡 Gelernt: Systemvorbereitung, Performance-Optimierung, Hardware-Kompatibilität.

✅ Abgeschlossen

Docker Homelab – Case Study

Docker WSL2 Linux

🎯 Ziel: Eine Multi-Container-Umgebung mit Webserver, PHP und Datenbank aufsetzen.

📦 Technologien: WSL2 → Ubuntu 24.04 → Docker → docker-compose.yml

🏗️ Architektur: Nginx → PHP 8.2 → MariaDB

⚠️ Problem: PHP-Container konnte keine Verbindung zur MariaDB herstellen.

🔍 Analyse: Logs überprüft mit docker logs → Netzwerk-Konfiguration kontrolliert.

✅ Lösung: Docker-Compose-Netzwerk angepasst und php-mysql Erweiterung installiert.

📈 Ergebnis: Alle Container kommunizieren miteinander, Anwendung läuft.

💡 Gelernt: Containerisierung, Docker-Netzwerke, Volumes, Troubleshooting mit Logs.

✅ Läuft

Gästebuch – Dynamische Webanwendung

PHP MySQL Webentwicklung

🎯 Ziel: Eine Webseite, auf der Besucher Nachrichten hinterlassen können.

⚙️ Funktionsweise: Formular → INSERT in Datenbank → SELECT für Anzeige.

⚠️ Problem: Die Uhrzeit der Einträge war falsch (UTC statt deutscher Zeit).

🔍 Analyse: PHP-Konfiguration geprüft → date.timezone war nicht gesetzt.

✅ Lösung: In der PHP-Konfiguration date.timezone = Europe/Berlin gesetzt.

📈 Ergebnis: Einträge werden mit korrekter deutscher Zeit gespeichert.

💡 Gelernt: PHP + MySQLi, SQL-Befehle, Container-Kommunikation, Konfiguration von PHP.

✅ Funktioniert live
